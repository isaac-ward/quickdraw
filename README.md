# Template Python Repository

# Prerequisites

- Install uv from https://uv.readthedocs.io/en/latest/installation.html

# Running this

We're set up with uv. I've already ran:

```bash
uv init
```

To install dependencies use:

```bash
uv sync
```

To run the project use:

```bash
uv run python src/template/main.py
```

# Reconfiguring as a new project

You should change:
- The project name in pyproject.toml
- The package folder name under src/
- This README.md file
